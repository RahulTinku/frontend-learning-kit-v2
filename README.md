# frontend-learning-kit-v2

> The definitive roadmap for frontend platform engineers.

## Status
🚧 Work in progress

## What it is

A structured, web-based resource for engineers who want to go beyond feature work into platform engineering. Like [roadmap.sh](https://roadmap.sh) but specifically for frontend platform engineers.

## Sections (planned)

- Frontend Platform Engineering roadmap
- Design Systems deep-dive
- Micro-frontends & Module Federation
- Developer Experience (DX) engineering
- AI tooling for frontend developers
- Curated reading list (RFCs, blog posts, talks)

## Tech stack

- [Next.js 15](https://nextjs.org) + App Router
- [MDX](https://mdxjs.com) — content in Markdown with React components
- [Tailwind CSS](https://tailwindcss.com) + [@tailwindcss/typography](https://tailwindcss.com/docs/typography-plugin)
- Hosted on [Vercel](https://vercel.com)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
